# Aman System v15.5.1 — نسخة أندرويد (تثبيت جديد)

هذه النسخة تبني واجهة Vue 3 + PrimeVue الموجودة في نسخة الكمبيوتر v15.5.1 فوق مشروع Android (Capacitor)، مع الإبقاء على كود Android الخاص بالكاميرا ومشاركة الملفات. لا تُنسخ ملفات Electron أو مكتبة الملفات الخاصة بويندوز.

## بناء APK من GitHub (الطريقة الموصى بها)
1. افتح المستودع على GitHub ثم تبويب **Actions**.
2. اختر **Android APK** ثم **Run workflow**.
3. انتظر اكتمال البناء بنجاح.
4. افتح نتيجة التشغيل ونزّل artifact باسم **AmanSystem-apk**؛ بداخله الملف `app-debug.apk`.

يمكن أيضًا تشغيل البناء تلقائيًا عند دفع تغييرات إلى الفرع الرئيسي أو فرع تجهيز Android.

## بناء APK على Windows
1. ثبّت Node.js LTS وAndroid Studio، وافتح Android Studio مرة واحدة لتثبيت Android SDK.
2. شغّل `build-apk.bat` من هذا المجلد.
3. الناتج: `android\\app\\build\\outputs\\apk\\debug\\app-debug.apk`.

## التثبيت لأول مرة
- انقل `app-debug.apk` إلى الهاتف وافتحه، واسمح بالتثبيت من هذا المصدر عند طلب Android ذلك.
- إذا كان إصدار Aman System القديم مثبتًا بتوقيع مختلف، أزِله أولًا ثم ثبّت APK الجديد. **إزالة التطبيق قد تمسح بياناته المحلية**؛ صدّر نسخة احتياطية من الإصدار القديم قبل إزالته إذا كانت بياناته مهمة.
- هذه النسخة تستخدم نفس معرف التطبيق `com.aman.system`، وبياناتها مستقلة عن نسخة الكمبيوتر.

## البيانات والميزات على Android
- بيانات النظام ومستندات الموظفين محفوظة محليًا داخل التطبيق (localStorage وIndexedDB)، ولا تتم مزامنتها تلقائيًا مع الكمبيوتر.
- رفع الصور وPDF من الهاتف مدعوم؛ تصدير النسخ الاحتياطية وExcel والتقارير يفتح قائمة المشاركة/الحفظ.
- المسح الضوئي المباشر ومراقبة مجلد ماسح Windows والطباعة المباشرة وميزات مكتبة ملفات Windows تظل خاصة بسطح المكتب.
- واجهة Vue الجديدة تستخدم نفس بيانات النظام ومفاتيح التخزين القديمة؛ لا يوجد ترحيل تلقائي من بيانات تطبيق Android قديم بعد إزالته.
- APK الناتج للتجربة موقّع بمفتاح debug. النشر على Google Play يحتاج إعداد توقيع release منفصلًا.

## حالة الاختبار
إضافة ملفات Vue وإعداد البناء إلى المستودع لا تعني أن APK اختُبر على هاتف حقيقي. حالة البناء الفعلية تُحدَّث بعد تشغيل GitHub Actions، ثم يلزم اختبار الكاميرا ورفع الملفات وOCR والمشاركة على جهاز Android.
