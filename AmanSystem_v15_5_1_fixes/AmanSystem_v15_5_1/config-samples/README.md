# ملفات الإعدادات النموذجية

| الملف | يقابل | ملاحظة |
|---|---|---|
| `aman-config.sample.json` | `%APPDATA%\Aman System\aman-config.json` على جهاز المستخدم | يُنشئه البرنامج تلقائيًا ويحدّثه من صفحة الإعدادات (مكان المكتبة، الطابعة، الماسح). **لا تحتاج** لإنشائه يدويًا. |
| `android-signing.sample.properties` | مفتاح توقيع أندرويد (release) | غير مستخدم حاليًا. المفتاح الحقيقي (`.jks`) وكلمات مروره يحتفظ بهما المستخدم وحده خارج المشروع. |
| `desktop-signing.sample.env` | شهادة توقيع ويندوز (electron-builder) | اختياري؛ غير مستخدم حاليًا. |

**لم يُضمَّن في الأرشيف أي:** كلمات مرور، مفاتيح API، مفاتيح توقيع، إعدادات Supabase، بيانات موظفين حقيقية.
(بيانات البرنامج الحقيقية موجودة فقط داخل جهاز المستخدم: localStorage وIndexedDB ومجلد المكتبة.)
